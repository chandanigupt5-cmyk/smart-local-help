SMART LOCAL HELP - LANDING PAGE

- README.txt : setup notes

How to run:
1. Extract the project.
2. Open index.html in Chrome/Edge.
3. Internet is required for the Tailwind CSS CDN.

Technology:
- HTML5
- Tailwind CSS v4 browser CDN
- Small vanilla JavaScript only for the mobile navigation menu

No build tool or Node.js is required.
